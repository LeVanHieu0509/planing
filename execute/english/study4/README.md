## ✅ TRACKING RULE - TẤT CẢ TOEIC PHẢI CÓ HISTORY

Mỗi hoạt động TOEIC đều phải để lại dấu vết trong tracker:

| Hoạt động                 | Ghi vào file                                                     | Dữ liệu tối thiểu                           |
| ------------------------- | ---------------------------------------------------------------- | ------------------------------------------- |
| Làm từng Part trên Study4 | `DAILY_LOG.md` + folder part tương ứng                           | ngày, test, score, %, thời gian, lỗi chính  |
| Chữa lỗi                  | `ERROR_ANALYSIS.md` + folder part tương ứng                      | câu sai, mã lỗi, pattern, bài học           |
| Dashboard cải thiện       | `PERFORMANCE_DASHBOARD.md`                                       | score history, trend, weakness, next action |
| Từ vựng                   | `VOCABULARY_TRACKER.md`                                          | từ, nghĩa, IPA, ngày học/ôn, trạng thái nhớ |
| Grammar                   | `GRAMMAR_ROADMAP.md` hoặc note grammar trong `personal/grammar/` | chủ đề, rule, ví dụ, câu sai liên quan      |
| Weekly/full mock          | `toeic/MOCK_TEST_TRACKER.md`                                     | L/R/Total, part yếu, 3 action items         |
| Official test             | `toeic/MOCK_TEST_TRACKER.md`                                     | điểm thật, lệ phí, so sánh với mock         |

Không tính là "done" nếu chỉ làm bài mà chưa ghi score + lỗi chính.
