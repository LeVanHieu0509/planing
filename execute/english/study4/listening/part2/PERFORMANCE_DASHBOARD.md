```
🥇 PRIORITY #1: YES/NO (56.5%) - Nhiều câu nhất, hay sai Indirect Answer
   → Học thuộc 5 dạng Indirect: I'm not sure / It depends / Redirect / Sure / Why don't you
   → QUY TẮC: Từ giống = BẪY → 90% sai → BỎ QUA

🥈 PRIORITY #2: Trần thuật (57.9%) - Statement = KHÔNG hỏi → phản hồi logic
   → Nghe TOPIC → chọn đáp án LIÊN QUAN logic
   → KHÔNG chọn đáp án có từ giống câu nói

🥉 PRIORITY #3: Tag Questions (50%) - Số lượng ít nhưng accuracy thấp
   → BỎ QUA đuôi (doesn't it? / have you?)
   → Chỉ cần hiểu NỘI DUNG CHÍNH → trả lời như YES/NO
```
