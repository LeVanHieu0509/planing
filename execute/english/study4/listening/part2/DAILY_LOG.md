**Root cause phân tích:**

🔴 **Vấn đề 1 - YES/NO (40%):**

```
TOEIC dùng "Indirect answers" thay vì Yes/No thật:
❌ Q: "Is the report ready?" → WRONG: "Yes, I can."
✅ ĐÚNG: "It will be done by noon." (không nói Yes/No, nhưng trả lời gián tiếp)

5 dạng indirect answer hay gặp:
1. "I'm not sure." / "I'll have to check." → khi không biết
2. "You should ask Mr. Kim." → chỉ người khác
3. "It depends on..." → điều kiện
4. "Sure." / "No problem." → request trả lời bằng willingness
5. Redirect: "Check with the HR department."

→ Action W1: Luyện nhận dạng 5 dạng này trong 50 câu YES/NO
```

🔴 **Vấn đề 2 - Tag questions (0%):**

```
Cấu trúc: Câu khẳng định + đuôi phủ định (VÀ NGƯỢC LẠI)
"The meeting starts at 9, doesn't it?" → nghe "doesn't it?" → biết hỏi về "starts at 9"
"You haven't submitted the report, have you?" → nghe "have you?" → biết hỏi "submitted or not"

Chiến thuật: BỎ QUA đuôi câu → chỉ cần hiểu NỘI DUNG CHÍNH của câu
→ Action W1: Học lý thuyết tag questions + 15 câu drill
```

🔴 **Vấn đề 3 - Choice/Request (33%):**

```
Choice: "A or B?" → phải nghe được CẢ HAI options và so sánh
Request: "Could you...?" → trả lời bằng cách NÓI CÓ ĐI KHÔNG, không nói khả năng
```
