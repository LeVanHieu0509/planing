## 📋 CÁC DẠNG BÀI PART 5 TOEIC

| Dạng bài                  | Mô tả                 | Tỷ trọng | Mẹo                                    |
| ------------------------- | --------------------- | -------- | -------------------------------------- |
| **Từ loại (Word Form)**   | Chọn đúng N/V/Adj/Adv | ~30%     | Nhìn vị trí chỗ trống trong câu        |
| **Từ vựng (Vocabulary)**  | Chọn từ đúng nghĩa    | ~25%     | Phải hiểu nghĩa cả câu                 |
| **Thì (Tense)**           | Chọn đúng thì động từ | ~10%     | Tìm dấu hiệu thời gian                 |
| **Đại từ (Pronoun)**      | Chọn đúng loại đại từ | ~10%     | Xem vai trò trong câu (S/O/Possessive) |
| **Giới từ (Preposition)** | Chọn đúng giới từ     | ~10%     | Học thuộc cụm cố định                  |
| **Liên từ (Conjunction)** | Chọn đúng từ nối      | ~5%      | Xem quan hệ logic giữa 2 vế            |
| **Trạng từ (Adverb)**     | Chọn đúng trạng từ    | ~5%      | Bổ nghĩa cho V/Adj/câu                 |
| **Thể (Voice)**           | Active vs Passive     | ~5%      | S + be + V3/ed = Passive               |
