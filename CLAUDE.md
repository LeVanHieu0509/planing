This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Repo Is

This is a **personal life planning system** (not a code project) for Hieu Le Van, organized as Markdown files managed with Scrum/Agile methodology. It covers: English learning (TOEIC + immersion), career (TMA + BIT + Miracle POS), finance, health/gym, MBA prep, and TikTok content.

All content is in **Vietnamese** unless otherwise noted. Respond in Vietnamese when editing or discussing planning files.

## Repository Structure

- `START_HERE.md` - Quick-start overview, daily schedule, current priorities
- `MASTER_PLAN.md` - 6-epic master plan, financial overview, 10-year vision
- `english/toeic/` - TOEIC study materials (roadmap, grammar, vocabulary, part-by-part tips, mock test tracker)
- `english/communication/` - English immersion roadmap (14/07/2026 - 14/01/2027)
- `execute/english/` - Execution logs: daily study sessions, mock test results, class prep notes
- `me/finance/` - Financial tracking and 2026-2028 financial plan
- `me/career/` - Career plans: Miracle POS, TikTok, TMA notes, master's degree prep
- `me/lifestyle/` - Daily schedule, gym plan, meal plan, self-understanding, relationships
- `scrum/` - Scrum framework, sprint calendar, individual sprint files (`sprints/S1.md`, etc.)
- `business/` - MBA coursework notes (marketing, management, brand management, quantitative analysis, business communication)
- `miracle/` - Miracle POS business deals and TikTok content drafts
- `programing/` - Programming study notes (Flutter CI/CD, AI agents, VS Code extension)

## Key Conventions

- **Sprint system**: 2-week sprints (Mon-Sun), tracked in `scrum/sprints/S{N}.md`. Sprint ceremonies happen Sunday 21:00.
- **6 Epics**: E1 English, E2 Communication, E3 Work, E4 Personal, E5 TikTok, E6 Relationships - with story point weights defined in `scrum/SCRUM_FRAMEWORK.md`.
- **Velocity**: 28-32 SP normal sprints, 20-25 SP recovery sprints (every 7th sprint).
- **Financial tracking**: Monthly tracker in `me/finance/MONTHLY_TRACKER.md`, projections in `me/finance/TAI_CHINH_2026_2028.md`.
- **Dates matter**: When updating planning files, use absolute dates (not relative like "next week"). Current sprint dates are in `scrum/sprints/` and `START_HERE.md`.

## When Editing Planning Files

- Keep the existing formatting style: tables, code blocks for schedules, emoji headers.
- Update the `_Cap nhat:` footer line at the bottom of files when making changes.
- Cross-reference related files using relative Markdown links (e.g., `[MASTER_PLAN.md](./MASTER_PLAN.md)`).
- Financial numbers must stay consistent across `START_HERE.md`, `MASTER_PLAN.md`, and `me/finance/` files.
