## 1. 💇 HAIR - Tóc (Scan từ đầu xuống)

**Mẹo: Tưởng tượng đứng trước gương, nhìn từ tóc → mặt**

| Từ vựng        | Nghĩa           | Mẹo nhớ                           |
| -------------- | --------------- | --------------------------------- |
| **Straight**   | Tóc thẳng       | Straight = thẳng (đường thẳng)    |
| **Curly**      | Tóc xoăn        | Curly = cuộn tròn                 |
| **Wavy**       | Tóc gợn sóng    | Wave = sóng biển 🌊               |
| **Blonde**     | Tóc vàng        | Nghĩ tới người phương Tây         |
| **Bald**       | Hói đầu         | **B**ald = **B**óng đầu           |
| **Going bald** | Đang bị hói dần | Going = đang tiến tới             |
| **Wig**        | Tóc giả         | Đội lên đầu → giả                 |
| **Dyed**       | Nhuộm toàn bộ   | Dyed = change **ALL** hair colour |
| **Highlights** | Nhuộm light     | **Little bits** of colour change  |
| **Eyebrows**   | Lông mày        | Eye + Brow (trán) = phía trên mắt |
| **Eyelash**    | Lông mi         | Eye + Lash = mi mắt               |
| **Beard**      | Râu (cằm)       | 🧔                                |

## 2. 📏 HEIGHT - Chiều cao

**Mẹo: Nhớ cặp đối lập + so sánh 3 bậc**

| Từ / Cấu trúc            | Nghĩa              |
| ------------------------ | ------------------ |
| **How tall are you?**    | Bạn cao bao nhiêu? |
| **I'm 1.5m / 150cm**     | Tôi cao 1m5        |
| **Meters / Centimeters** | Mét / Centimet     |
| **More than 100cm**      | Hơn 100cm          |

**So sánh 3 bậc:**

```
Tall  →  Taller  →  Tallest   (cao)
Short →  Shorter →  Shortest  (thấp)
```

---

## 3. ⚖️ WEIGHT - Cân nặng

**Mẹo: Xếp từ GẦY → BÉO**

```
Thin → Chubby → Fat / Big / Overweight
(gầy)  (mũm mĩm)   (béo / thừa cân)
```

| Từ vựng                    | Nghĩa            | Mẹo nhớ                   |
| -------------------------- | ---------------- | ------------------------- |
| **Weight** (n)             | Cân nặng         |                           |
| **I weigh \_\_ kilograms** | Tôi nặng \_\_ kg |                           |
| **Thin**                   | Gầy              | Thin = mỏng = gầy         |
| **Chubby**                 | Mũm mĩm          | Chubby = cute béo         |
| **Fat / Big / Overweight** | Béo / Thừa cân   | Over + weight = quá cân   |
| **Beer belly**             | Bụng bia 🍺      | Beer = bia + Belly = bụng |
| **Waist**                  | Vòng eo          |                           |

## 5. 😍 MÔ TẢ NGOẠI HÌNH - Tính từ

**Mẹo: Xếp theo mức độ từ THẤP → CAO**

```
Cute → Pretty → Nice → Beautiful → Gorgeous → Sexy
(dễ thương) (xinh)  (dễ nhìn) (đẹp)    (cực đẹp)  (gợi cảm)
```

| Từ vựng           | Dùng cho     | Mẹo nhớ                          |
| ----------------- | ------------ | -------------------------------- |
| **Cute**          | Cả hai       | Dễ thương, nhỏ nhắn              |
| **Pretty**        | Chủ yếu nữ   | Xinh xắn                         |
| **Nice**          | Cả hai       | Dễ nhìn, dễ chịu                 |
| **Beautiful**     | Man / Woman  | Đẹp (dùng rộng)                  |
| **Handsome**      | **Men only** | Đẹp trai → **H**andsome = **H**e |
| **Gorgeous**      | Man / Woman  | Cực kỳ đẹp                       |
| **Attractive**    | Cả hai       | Attract = thu hút → hấp dẫn      |
| **Sexy**          | Cả hai       | Gợi cảm                          |
| **Cool**          | Cả hai       | Ngầu                             |
| **Gentleman**     | Men          | Quý ông, lịch lãm                |
| **Ugly**          | Cả hai       | Xấu                              |
| **Uncomfortable** |              | Không thoải mái                  |

**Mẹo cặp đối lập:**

```
Attractive  ↔  Ugly
Beautiful   ↔  Ugly
Comfortable ↔  Uncomfortable
```

## 7. 🧠 MẸO GHI NHỚ TỔNG HỢP

### Mẹo 1: Scan từ ĐẦU → CHÂN

```
🧠 Đầu    → Bald, Going bald, Wig
💇 Tóc    → Straight, Curly, Wavy, Blonde, Dyed, Highlights
👁️ Mặt    → Eyebrows, Eyelash, Beard, Moustache
📏 Cao    → Tall, Short + so sánh (-er, -est)
⚖️ Nặng   → Fat, Overweight, Thin, Chubby, Beer belly
💪 Hình   → Muscular, Curvy, Energetic
```

### Mẹo 2: Nhớ cặp đối lập (nhớ 1 = nhớ 2)

```
Tall       ↔  Short
Fat        ↔  Thin
Straight   ↔  Curly
Attractive ↔  Ugly
Bald       ↔  Highlights / Dyed
```

### Mẹo 3: Phân biệt hay nhầm

| Hay nhầm                   | Cách nhớ                                       |
| -------------------------- | ---------------------------------------------- |
| **Dyed** vs **Highlights** | Dyed = ALL / Highlights = little bits          |
| **Salon** vs **Barber**    | Sa**L**on = **L**adies / **B**arber = **B**oys |
| **Muscle** vs **Muscular** | Muscle = noun / Muscular = adjective           |

## 8. 🏋️ BÀI TẬP LUYỆN NÓI

### Bài 1: Tự mô tả bản thân

```
"I'm 1m70. I weigh 65 kilograms.
I have straight black hair. I'm thin and energetic.
I got a haircut at the barber last week."
```

### Bài 2: Mô tả bạn thân

```
"My friend is tall and muscular. He has a beard.
He is handsome and cool. He has short straight hair."
```

### Bài 3: Mô tả người nổi tiếng

```
"She has curly blonde hair. She is gorgeous and attractive.
She is curvy. She always looks comfortable in her style."
```

> **Mẹo vàng:** Tối nay trước khi ngủ, mô tả 3 người bằng tiếng Anh. Làm 2-3 ngày là nhớ hết!
