## 1. CẤU TRÚC

| Dạng               | Công thức                   | Ví dụ                      |
| ------------------ | --------------------------- | -------------------------- |
| **(+) Khẳng định** | S + am/is/are + V-ing       | He **is working**.         |
| **(-) Phủ định**   | S + am/is/are + not + V-ing | They **aren't eating**.    |
| **(?) Câu hỏi**    | Am/Is/Are + S + V-ing?      | **Are** you **listening**? |

## 3. QUY TẮC VÀNG - KHÔNG BAO GIỜ QUÊN

> ✅ **Hễ thấy V-ing → chỉ dùng am/is/are - KHÔNG dùng do/does**

```
❌ Does she is working?     ✅ Is she working?
❌ Do they are eating?      ✅ Are they eating?
❌ She doesn't is studying. ✅ She isn't studying.
```

| Trợ động từ       | Dùng cho thì       | Đi với         |
| ----------------- | ------------------ | -------------- |
| **do / does**     | Present Simple     | V (nguyên mẫu) |
| **am / is / are** | Present Continuous | V-ing          |

---

## 4. CHIA am/is/are THEO CHỦ NGỮ

| Chủ ngữ                                    | Trợ động từ  |
| ------------------------------------------ | ------------ |
| **I**                                      | am           |
| **He / She / It**                          | is           |
| **Someone / Somebody / Nobody / Everyone** | **is** ⚠️    |
| **You / We / They**                        | are          |
| **The staff / The team**                   | are (thường) |

---

## 5. LỖI SAI HAY GẶP (từ bài tập hôm nay)

### ❌ Lỗi 1: Quên đuôi -ing

```
❌ is study   → ✅ is studying
❌ is bring   → ✅ is bringing
❌ am write   → ✅ am writing
```

**Cách nhớ:** Nhẩm "am/is/are → ... → -ing" trước khi viết.

### ❌ Lỗi 2: Nhầm Someone/Nobody → dùng "are"

```
❌ Someone are knocking → ✅ Someone IS knocking
❌ Nobody are working  → ✅ Nobody IS working
❌ Everyone are eating → ✅ Everyone IS eating
```

### ❌ Lỗi 3: Nhầm "you" → dùng "is"

```
❌ Is you using?  → ✅ Are you using?
```

## 6. SO SÁNH VỚI PRESENT SIMPLE - TOEIC TRAP ⚡

|               | Present Simple                    | Present Continuous            |
| ------------- | --------------------------------- | ----------------------------- |
| **Dấu hiệu**  | always, usually, every day, often | now, right now, at the moment |
| **Ý nghĩa**   | Thói quen / Sự thật chung         | Đang xảy ra ngay lúc nói      |
| **Công thức** | S + V(s/es)                       | S + am/is/are + V-ing         |
| **Phủ định**  | don't / doesn't                   | isn't / aren't                |
| **Câu hỏi**   | Do / Does                         | Am / Is / Are                 |

**Ví dụ TOEIC:**

```
She drinks coffee every morning.      → Present Simple (thói quen)
She is drinking coffee right now.     → Present Continuous (đang làm)

The restaurant serves breakfast.      → Present Simple (sự thật chung)
The waiter is serving table 5 now.    → Present Continuous (đang xảy ra)
```
