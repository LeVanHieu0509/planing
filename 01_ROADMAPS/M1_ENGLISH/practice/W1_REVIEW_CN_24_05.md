### FIX #1: Phân từ (-ing / -ed) - 20% → cần ≥60%

```
QUY TẮC:
→ V-ing: Miêu tả VẬT/TÌNH HUỐNG gây ra cảm xúc
   "an interesting report" = báo cáo gây hứng thú
   "a boring meeting" = cuộc họp gây nhàm chán

→ V-ed: Miêu tả NGƯỜI cảm nhận cảm xúc
   "an interested reader" = người đọc cảm thấy hứng thú
   "a bored employee" = nhân viên cảm thấy nhàm chán

5 CẶP CẦN THUỘC:
  boring / bored
  exciting / excited
  confusing / confused
  satisfying / satisfied
  surprising / surprised

TRICK NHANH:
  Chủ ngữ là NGƯỜI → dùng V-ed (bored, excited, confused)
  Chủ ngữ là VẬT   → dùng V-ing (boring, exciting, confusing)
```

**Bài tập tự kiểm tra (5 câu):**

```
1. The presentation was very _______. (interest)
2. She felt _______ after the long meeting. (exhaust)
3. The _______ results surprised everyone. (disappoint)
4. We received some _______ feedback. (encourage)
5. The employees were _______ by the announcement. (confuse)

ĐÁP ÁN:
1. interesting (vật: presentation)
2. exhausted (người: she)
3. disappointing (vật: results)
4. encouraging (vật: feedback)
5. confused (người: employees)
```

### FIX #2: Cấu trúc so sánh - 16.7% → cần ≥60%

```
QUY TẮC:
1. SO SÁNH HƠN:
   Adj ngắn: adj + -er + than     → "faster than"
   Adj dài:  more + adj + than    → "more expensive than"

2. SO SÁNH NHẤT:
   Adj ngắn: the + adj + -est     → "the fastest"
   Adj dài:  the most + adj       → "the most expensive"

3. SO SÁNH BẰNG:
   as + adj + as                  → "as fast as"

4. BẤT QUY TẮC:
   good → better → the best
   bad → worse → the worst
   far → farther/further → the farthest/furthest
   many/much → more → the most
   little → less → the least

TRAP THƯỜNG GẶP:
❌ "more faster" → ĐÃ CÓ -er thì KHÔNG thêm more
❌ "most biggest" → ĐÃ CÓ -est thì KHÔNG thêm most
❌ "as fast than" → as...as, KHÔNG phải as...than
```

### FIX #3: Tính từ (Adjective) - 44.4% → cần ≥60%

```
VỊ TRÍ TÍNH TỪ:
1. ___ + NOUN → Cần ADJECTIVE
   "A ___ decision" → decisive/important

2. be/seem/become/feel + ___ → Cần ADJECTIVE
   "The result is ___" → satisfactory

3. Verb thường + ___ → Cần ADVERB (KHÔNG phải adj!)
   "He works ___" → efficiently (KHÔNG phải efficient)

ĐUÔI NHẬN DẠNG:
  ADJ: -ful, -less, -ive, -able, -ible, -al, -ous, -ent, -ant, -ary
  ADV: -ly (carefully, efficiently, successfully)
  NOUN: -tion, -ment, -ness, -ity, -ance, -ence
  VERB: -ize, -fy, -en, -ate

PHÂN BIỆT ADJ vs ADV:
  "She is a careful driver." → careful = ADJ (trước noun)
  "She drives carefully." → carefully = ADV (sau verb)
```

### FIX #4: Thể bị động (Active/Passive) - 46.2% → cần ≥60%

```
QUY TẮC:
  ACTIVE:  S + V + O          → "The manager approved the plan."
  PASSIVE: S + be + V3 + by   → "The plan was approved by the manager."

KHI NÀO DÙNG PASSIVE:
  → Chủ ngữ BỊ tác động → dùng be + V3
  → "The report ___ (submit) yesterday." → was submitted
  → "Employees ___ (require) to attend." → are required

CÁC DẠNG PASSIVE:
  Present:     is/are + V3        → "is submitted"
  Past:        was/were + V3      → "was submitted"
  Future:      will be + V3       → "will be submitted"
  Present Perf: has/have been + V3 → "has been submitted"
  Modal:       can/should be + V3  → "should be submitted"

TRAP:
  ❌ "The report submitted" → thiếu "was"
  ❌ "was submitting" → submitting = active, submitted = passive
```

### FIX #5: Thì (Tense) - 50% → cần ≥60%

```
CÁC THÌ HAY GẶP TRONG TOEIC:

1. PRESENT SIMPLE (thường xuyên, sự thật):
   "The company produces electronic devices."
   Dấu hiệu: always, usually, every day, often

2. PRESENT CONTINUOUS (đang xảy ra):
   "We are currently reviewing the proposal."
   Dấu hiệu: now, currently, at the moment

3. PAST SIMPLE (đã xong):
   "The team completed the project last week."
   Dấu hiệu: yesterday, last week, ago, in 2024

4. FUTURE (sẽ):
   "The meeting will start at 3 PM."
   Dấu hiệu: tomorrow, next week, will, be going to

5. PRESENT PERFECT (đã làm, còn liên quan hiện tại):
   "She has worked here since 2020."
   Dấu hiệu: since, for, already, yet, recently

MỆNH ĐỀ THỜI GIAN (HAY SAI!):
  "When/Before/After/By the time + PRESENT SIMPLE" (KHÔNG dùng will!)
  ❌ "When he will arrive..." → ❌
  ✅ "When he arrives..." → ✅
  → Main clause VẪN dùng will: "When he arrives, we will start."
```

### FIX P2-1: YES/NO - 56.5% (13 đúng / 10 sai)

```
VẤN ĐỀ: TOEIC dùng INDIRECT ANSWER thay vì Yes/No thẳng

5 DẠNG INDIRECT ANSWER:

1. "I'm not sure." / "I'll have to check."
   → Khi câu hỏi hỏi info mình chưa biết

2. "Why don't you...?" / "You should..."
   → Dùng cho câu Why/How

3. "It depends on..." / "That depends."
   → Không trả lời thẳng YES/NO

4. "Sure." / "No problem." / "Of course."
   → Request → trả lời bằng willingness

5. "You should ask Mr. Kim about that."
   → Không biết → chỉ người khác (Redirect)

CHIẾN THUẬT:
✅ Nghe câu hỏi → xác định HỎI GÌ
✅ Đáp án không cần có Yes/No → vẫn có thể ĐÚNG
❌ Đáp án có từ GIỐNG câu hỏi → 90% là BẪY
```

---

### FIX P2-2: Trần thuật - 57.9% (11 đúng / 8 sai)

```
ĐẶC ĐIỂM: Câu trần thuật KHÔNG hỏi → KHÔNG trả lời Yes/No
Thay vào đó: PHẢN HỒI logic

VD:
  "I just spoke with Jonathan on the phone."
  ❌ "Yes, he's on the phone." → repeat trap!
  ✅ "Oh, is he feeling better?" → phản hồi logic

CHIẾN THUẬT:
1. Nghe câu → xác định TOPIC (nói về cái gì?)
2. Đáp án phải LIÊN QUAN logic đến topic
3. Từ giống câu nói = BẪY → BỎ QUA
```

---

### FIX P2-3: Tag Questions - 50% (5 đúng / 5 sai)

```
CẤU TRÚC:
  Khẳng định + đuôi phủ định: "The meeting starts at 9, doesn't it?"
  Phủ định + đuôi khẳng định: "You haven't submitted, have you?"

CHIẾN THUẬT:
  → BỎ QUA phần đuôi (doesn't it? / have you?)
  → CHỈ CẦN hiểu NỘI DUNG CHÍNH
  → Trả lời như YES/NO bình thường

VD: "The report is due tomorrow, isn't it?"
  → Topic: report due tomorrow
  ✅ "Yes, by end of business day."
  ❌ "Tomorrow at the meeting." → không trả lời đúng câu hỏi
```
