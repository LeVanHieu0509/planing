## ⚡ CHIẾN THUẬT KHI LÀM ĐỀ ETS

### Khi drill từng part (Luyện tập mode):

```
1. Làm bài → chấm điểm
2. Review TỪNG CÂU SAI:
   - Câu hỏi nói gì?
   - Tại sao chọn sai? (L-REP? L-IND? R-VOC?)
   - Đáp án đúng tại sao đúng?
3. Ghi lỗi vào tracking
4. Focus: Part 2 (REI + V/O) + Part 5 (Context Locking)
```

### Khi mock (Thi thử mode):

```
1. Căn đúng 120 phút - KHÔNG PAUSE
2. Làm xong → chấm điểm → ghi tổng vào tracking
3. Chữa chi tiết từng part
4. So sánh với mock trước → trend lên hay xuống?
```

### QUY TẮC VÀNG:

```
🔥 Part 2: TỪ GIỐNG = BẪY → BỎ QUA → CHỌN TỪ KHÁC ĐÚNG Ý
🔥 Part 2: Bắt V (verb) + O (object) → Loại sai dạng → Loại sai chủ đề → Chọn
🔥 Part 5: ĐỌC ĐỦ CỤM TRƯỚC/SAU → KHÔNG CHỌN THEO 1 KEYWORD
🔥 YES/NO: Dùng kỹ thuật REI (Repeat → Eliminate → Indirect)
```
