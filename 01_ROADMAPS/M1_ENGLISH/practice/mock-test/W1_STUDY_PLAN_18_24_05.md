## ⚡ QUICK REFERENCE - PATTERN CẦN NHỚ TUẦN NÀY

### Part 2 - 5 Dạng Indirect Answer (Hay ra nhất):

```
1. "I'm not sure." / "I don't know." / "I'll have to check."
   → Dùng khi câu hỏi hỏi thông tin mình chưa biết

2. "Why don't you...?" / "You should..."
   → Dùng cho câu Why/How

3. "It depends on..." / "That depends."
   → Indirect, không trực tiếp YES/NO

4. "Can you...?" → "Sure." / "No problem." / "Of course."
   → Request được trả lời bằng willingness, không phải ability

5. Redirect: "You should ask Mr. Kim about that."
   → Không biết → chỉ người khác
```

### Part 5 - Nhận dạng Adjective nhanh:

```
Vị trí 1: ___ + NOUN → Cần ADJECTIVE
  "A ___ decision" → decisive/important/significant

Vị trí 2: be/seem/become/feel + ___ → Cần ADJECTIVE
  "The result is ___" → satisfactory/successful/positive

Vị trí 3: Verb + ___ → Cần ADVERB (KHÔNG phải adjective!)
  "He works ___" → efficiently (NOT efficient)

Đuôi ADJECTIVE: -ful, -less, -ive, -able, -ible, -al, -ous, -ent, -ant, -ary
Đuôi ADVERB: -ly (carefully, efficiently, successfully)
```
