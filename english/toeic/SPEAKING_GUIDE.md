## 📝 TIPS VÀNG

### 5 KHÔNG:

```
1. KHÔNG dịch từ tiếng Việt sang Anh trong đầu → Học PATTERNS
2. KHÔNG sợ nói sai → Nói sai 100 lần tốt hơn không nói
3. KHÔNG học ngữ pháp trước khi nói → Học CHUNKS trước
4. KHÔNG nghe chậm để hiểu → Nghe tốc độ bình thường (1x)
5. KHÔNG chỉ nghe mà không NÓI → Shadowing = phải nói theo
```

### 5 LUÔN:

```
1. LUÔN ghi âm bản thân (Voice Recorder mỗi ngày)
2. LUÔN nói TO và RÕ (như đang trình bày trước 10 người)
3. LUÔN luyện vào CÙNG GIỜ (20:30-20:55 tối)
4. LUÔN học theo CHỦ ĐỀ (1 tuần = 1 chủ đề)
5. LUÔN tự thưởng bản thân (nghe lại bản ghi tuần trước)
```

## 🎧 KỸ THUẬT SHADOWING (25p/buổi)

```
BƯỚC 1: Nghe 1 lần (không nói) - 2p
  → Hiểu tổng quát nội dung

BƯỚC 2: Nghe + đọc subtitle - 2p
  → Hiểu cách liên âm, ngắt ngứt
  → Đánh dấu chỗ STRESS (trọng âm)

BƯỚC 3: Nghe + nói theo đồng thời - 5p
  → Bắt chước CHÍNH XÁC giọng nói
  → Tập trung: Intonation + Rhythm
  → Làm 3-5 lần

BƯỚC 4: Tắt video, tự nói lại - 3p
  → Ghi âm bản thân
  → So sánh với bản gốc

BƯỚC 5: Ghi chú - 3p
  → Từ/cụm từ mới
  → Cách phát âm đặc biệt
```

## 📚 SCRIPTS QUAN TRỌNG

### Phase 1: Tự giới thiệu (S1-S10)

**Script 1 - Basic (30 giây):**

```
"Hi, my name is Hieu. I'm 25 years old.
I'm a software developer at TMA Solutions in Ho Chi Minh City.
I've been working here for about [X] years.
I also do remote work for BIT company.
In my free time, I'm learning English and working on a side project
called Miracle POS."
```

**Script 2 - Detailed (1 phút):**

```
"Hello, let me introduce myself. My name is Hieu Le Van, and I'm
25 years old. I'm currently working as a software developer at TMA
Solutions, which is an outsourcing company in Ho Chi Minh City.

My daily work involves coding, code review, and collaborating with
my team. I also take on remote projects from BIT company on the side.

Right now, I'm studying for the TOEIC exam. My goal is to score 700
or above by March next year. I believe improving my English will
open more opportunities for international projects."
```

### Phase 2: Mô tả công việc (S11-S23)

**Script - Describing Your Project:**

```
"Let me tell you about the project I'm working on at TMA.
It's an outsourcing project for an international client.
We're building a web application using React for the frontend
and Node.js for the backend.

My main responsibilities include developing API endpoints,
writing unit tests, and doing code reviews. We follow Agile
methodology with two-week sprints."
```

**Script - Describing a Bug Fix:**

```
"I'd like to talk about a bug I fixed recently.
The issue was that users couldn't log in after resetting their password.
I started by reproducing the bug in the development environment.
The root cause was a mismatch between the password hash algorithm.
I fixed it by updating the reset function to use the same algorithm."
```

### Phase 3: Scrum & Meeting English (S24-S36)

**Script - Sprint Planning:**

```
"In this sprint, I'd like to focus on three main stories.
First, the user authentication module. I estimate this at 5 story points.
Second, the API for product management. This is about 3 story points.
Third, writing unit tests for the payment service. I estimate 2 points.
In total, that's 10 story points for this sprint."
```

**Mẫu câu Meeting:**

```
MỞ ĐẦU:
  "I'd like to share..." / "Let me give an update on..."

BÁO CÁO:
  "We've completed..." / "I'm currently working on..."
  "I expect to finish by..."

VẤN ĐỀ:
  "I want to flag a potential issue..."
  "We're facing a challenge with..."
  "There's a blocker I need help with..."

GỢI Ý:
  "I suggest we..." / "What if we..."
  "My recommendation is..."

ĐỒNG Ý/KHÔNG:
  "I agree with that approach."
  "I see your point, however..."
```

## 🗣️ PHÁT ÂM

### Âm khó cho người Việt:

```
/th/ → think, this   (lưỡi giữa 2 răng cửa)
/r/  → right, report (cuộn lưỡi ra sau)
/l/  → will, feel    (lưỡi chạm vòm miệng)
/v/  → very, view    (răng trên chạm môi dưới)
/z/  → is, has, does (rung dây thanh)
```

### Liên âm (Connected Speech):

```
"want to" → "wanna"    "going to" → "gonna"
"have to" → "hafta"    "kind of"  → "kinda"
"check it out" → "che-ki-dout"
"turn it off"  → "tur-ni-doff"
```

### Trọng âm:

```
Noun → trọng âm đầu: PROject, MANager, MEETing
Verb → trọng âm sau:  rePORT, deCIDE, prePARE
```
