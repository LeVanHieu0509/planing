## 🔥 VIRAL FORMULA ĐÃ ĐƯỢC CHỨNG MINH

### Pattern từ 3 video 100K+:

```

"#coding #dev #programming #hoclaptrinh #startup"
→ HOOK: Màn hình code + atmosphere
→ ANGLE: Dev life aesthetic
```

### CÔNG THỨC = **C.S.C.T**

```
C - CẢM XÚC MẠNH (Hook 0-2 giây đầu)
    → Đau, thách thức, thật thà, bất ngờ

S - SỐ LIỆU CỤ THỂ (Credibility)
    → "12 tiếng/ngày", "từ con số 0", "30 tuổi"

C - CÂU CHUYỆN THẬT (Story)
    → Hành trình, sai lầm, bài học

T - TRIGGER CỘNG ĐỒNG (CTA)
    → "join discord", "cùng nhau", "ai giống tôi không"
```

### Format tối ưu:

```
Duration: 0:23 - 0:39 giây (KHÔNG làm video dài)
Visual:   Màn hình code tối + đèn bàn + text overlay
Audio:    Original sound (không nhạc trending)
Caption:  Cảm xúc thật + hashtags: #dev #startup #coding #devlostartup
```

### ❌ KHÔNG LÀM (đã chứng minh thất bại):

```
- Content tiếng Anh/TOEIC: "Startup học từ vựng" = 2.8K, "học tiếng anh" = 4K
  → Audience KHÔNG quan tâm → sai niche hoàn toàn
- Video quá dài (1 phút+): Ngày 7 show = 5K views
- Storytelling dạng "ngày 1, ngày 2...": Drop dần dần
```
