## 🏋️ BÀI TẬP CHI TIẾT (60 PHÚT/BUỔI)

### T2 tối - PUSH DAY (Ngực + Tay sau + Vai trước)

```
Khởi động: 5p (xoay vai, chạy tại chỗ)

1. Bench Press (Đẩy ngực)        4×8-10   (tăng dần tạ)
2. Incline Dumbbell Press         3×10-12  (ngực trên)
3. Cable Fly / Pec Deck           3×12-15  (ép ngực)
4. Overhead Tricep Extension      3×10-12  (tay sau)
5. Tricep Pushdown (dây cable)    3×12-15  (tay sau)
6. Front Raise (tạ nhẹ)           3×12     (vai trước)

Giãn cơ: 5p
Tổng: ~55-60 phút
```

### T6 tối - PULL DAY (Lưng + Tay trước + Vai sau)

```
Khởi động: 5p

1. Lat Pulldown / Pull-up         4×8-10   (lưng rộng)
2. Seated Cable Row               3×10-12  (lưng dày)
3. Dumbbell Row (1 tay)           3×10-12  (lưng giữa)
4. Face Pull (dây cable)          3×15     (vai sau)
5. Barbell Curl                   3×10-12  (tay trước)
6. Hammer Curl                    3×12     (tay trước)

Giãn cơ: 5p
Tổng: ~55-60 phút
```

### T7 sáng - LEGS + SHOULDERS

```
Khởi động: 5p (squat không tạ, lunges nhẹ)

1. Barbell Squat                  4×8-10   (đùi trước + mông)
2. Leg Press                      3×10-12  (đùi tổng thể)
3. Romanian Deadlift              3×10     (đùi sau + mông)
4. Leg Curl                       3×12     (đùi sau)
5. Shoulder Press (tạ đôi)        3×10-12  (vai)
6. Lateral Raise                  3×15     (vai giữa)
7. Calf Raise                     3×15     (bắp chân)

Giãn cơ: 5p
Tổng: ~60 phút
```
